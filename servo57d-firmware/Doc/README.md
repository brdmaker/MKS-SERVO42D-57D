# Doc

Datasheets and the schematic used for the hardware notes in `../docs/`.

- `N32L406CBL7.pdf`: Nations N32L40x datasheet (covers the N32L403 and N32L406, 89 pages), the original as received.
- `N32L406CBL7.txt`: the same, extracted with `pdftotext -layout` for searching. Tables and pinout figures lose
  their layout in text; check the PDF for those.
- the rest: schematic, EG3013, MT6816, AP050N03Q and OLED datasheets from the upstream repository.
